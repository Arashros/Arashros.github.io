This project develops a reproducible machine-learning workflow to estimate chronological age from structural MRI morphometric measurements. It builds on my undergraduate experience analyzing MRI-derived anatomical data and presents a separate, portfolio-oriented modeling pipeline.

The workflow prepares participant-level features, compares regression models against a median-age baseline, and uses participant-grouped validation to prevent visits from the same participant appearing in both training and evaluation partitions.

**Tools:** Python, Pandas, NumPy, scikit-learn, Git  
**Repository:** [Brain-Age-Prediction](https://github.com/Arashros/Brain-Age-Prediction)

The repository README documents the dataset, setup, evaluation design, results, and limitations. This is a research portfolio project and not a clinical diagnostic tool.
